# ジャケット＋回るCD動画の作り方

ジャケットの横に半月のCD盤面を置き、盤面が時計回り（右回り）に10秒でちょうど1回転する動画を作る手順です。

フレームは Python（PIL）で1枚ずつ回転レンダリングする手続き的な生成で、**動画生成モデルは使いません**。10秒ループを作り、曲の長さ分繰り返して曲を載せます。元の画像そのものを回すので、盤面のデザインは劣化しません。

「Fleeting Four Seasons (Japanese ver.)」で完成した形の記録です。

## 完成形の仕様

| 項目 | 値 |
|---|---|
| フレーム | 1080×720（3:2） |
| 背景 | 白 |
| ジャケット | 左に 720×720 |
| 盤面の直径 | 640px（ジャケット高さ 720 に対して） |
| 盤面の位置 | 中心がジャケットの右端に一致。右半分だけが見える半月 |
| 回転 | 時計回り（実物のCDと同じ方向）、10秒でちょうど1回転、一定速度 |
| ループ | 10秒（240フレーム @24fps）を繰り返して曲の長さに合わせる |
| 音 | 曲をそのままミックス。動画の長さ＝曲の長さ |
| 出力 | H.264 / yuv420p / bt709 / faststart（iPhoneで再生できる形） |

## 用意するもの

- ジャケット画像（完成品。ケース込みの画像でも、デザイン面だけでもよい）
- 盤面デザイン画像（正方形・円形の盤面テクスチャ）
- 曲ファイル（長さはこのファイルに合わせる）

## 素材ベース（必須）

土台になるブランク素材を固定しておかないと、ケースや盤の寸法・位置が毎回ブレます。この4点を基準にしてください（リポジトリ直下、いずれも1600×1600）。

CD用：

- `IMG_3354.webp` — 無地の黒ジャケット（透明ジュエルケース入り、白い背帯つき）
  - デザイン面（黒いカード）の範囲： **x 201..1517、y 95..1547**。デザインはこの内側に貼る
- `IMG_3353.webp` — 無地・無印刷の銀色CD（白背景）
  - 盤の中心 **(770, 808)**、半径 **約700**（わずかに楕円気味なので、テクスチャ化の際に円へ正規化する）

レコード（LP）用 — 動画ルールはCDと同じ（半月、10秒で1回転）。レーベル面はジャケットのデザインから作り直す：

- `IMG_3356.jpeg` — 無地の黒LPジャケット（マットな黒スリーブ、白い背の縁つき）
  - デザイン面（黒い前面）の範囲： **x 52..1584、y 11..1593**
- `IMG_3357.jpeg` — 無地の黒LPレコード（白い無地レーベル）
  - 盤の中心 **(802, 802)**、半径 **768**、レーベルの半径 **約327**

ジャケットの黒い面がデザイン面です。ブランクは写真の上塗りで作らず、無地の物体として用意すること（質感と寸法が安定しません）。

## 盤面デザインのルール

実物のCDの印刷範囲を守ります。

- 地色は盤の縁まで全体に塗ってよい（ベた塗り全面）
- ただし**要素（文字・ロゴ）の配置は印刷できる帯の中**：外側は半径の93%まで、内側はハブのクリアゾーン（半径の約36%）には何も置かない
- ゾーニングの例：
- タイトル：上部中央
- 小さなマーク類：左右の中線あたり
- 曲目・情報行：下部中央
- 権利表記などの小さい文字：縁の内側に沿って
- ハブ周りはクリアのまま（ブランク素材のハブを残す）

## 手順

1. **盤面テクスチャを用意する** — 盤面デザインを正方形のテクスチャにする。円の中心と半径を素材に合わせる（生成画像の円検出は影や背景に引っ張られるので、彩度マスクの外接矩形で合わせる方法が安定した）。
2. **ジャケットを組む** — デザインをジャケット素材のデザイン面に貼る。
3. **バランス確認の静止画を1枚作る** — 完成形と同じ比率・配置で静止画を出し、**必ず承認を取ってから**動画化する。動かしてから直すと手戻りが大きい。
4. **10秒ループをレンダリングする** — `make_cd_video.py` がフレームを1枚ずつ生成して ffmpeg に流し込む。回転角はフレーム f に対して `-360 × f / 240` 度（PIL の `rotate` は正の角度が反時計回りなので、時計回りは負）。
5. **曲をミックスする** — ループを繰り返し、曲の長さで切る（下記のコマンド）。
6. **検証する** — 0°/90°/180°/270° 付近のフレームを抜いてコンタクトシートを作り、ハブがブレていないか、継ぎ目が出ていないかを目で確認する。数値チェックだけで通さない。
7. **新しいファイル名で出す** — 同じ名前で上書きすると、受け取る側のクライアントがキャッシュした古い版を表示することがある。版ごとに新しい名前（…_v2、…_v3）にする。

## 使い方

```bash
# バランス確認用の静止画
python3 make_cd_video.py --jacket jacket.jpg --disc disc_texture.png --still balance.png

# 10秒ループ
python3 make_cd_video.py --jacket jacket.jpg --disc disc_texture.png --loop loop10.mp4

# 曲をミックスして完成（138秒の曲の例）
ffmpeg -stream_loop 14 -i loop10.mp4 -i song.m4a \
-map 0:v -map 1:a -t 138.0 \
-c:v libx264 -pix_fmt yuv420p \
-color_primaries bt709 -color_trc bt709 -colorspace bt709 -color_range tv \
-crf 20 -maxrate 7000k -bufsize 14000k \
-c:a aac -b:a 192k -movflags +faststart -video_track_timescale 15360 \
output_v1.mp4
```

ミックス時の注意：`-shortest` とストリームコピーの組み合わせでは曲の長さで切れないことがある。再エンコードして `-t <曲の秒数>` で切る。

## AIに頼むときの仕様プロンプト

盤面・ジャケット・音源が決まっている前提で、AIエージェントにそのまま渡せる形：

```
PythonでCD動画を生成してください。


- ジャケット画像：<ファイル>
- CD盤面デザイン画像：<ファイル>
- 音源ファイル：<ファイル>（動画の長さは音源に合わせる）


- 画面サイズ 1080×720（3:2）、背景は白
- ジャケットは左側に720×720で配置
- CDはジャケットの右端に中心を合わせ、直径640px。
右半分だけが見える半月の形にする
- まず、この構成のバランス確認用静止画を1枚見せること。
承認してから動画化する


- 時計回り、10秒でちょうど1回転、一定速度
- 中心は動かさず、ブレ・ズームなし
- 盤面の印刷は盤と一体で回転させる


- 音源をそのままミックスし、回転ループをつないで音源の長さまで伸ばす
- H.264 / yuv420p / bt709 / faststart、iPhoneで再生できる形式
- 出力ファイル名は毎回新しい名前にする（上書きしない）
```
