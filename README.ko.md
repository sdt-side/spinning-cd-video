# 재킷 + 회전하는 CD 영상 만드는 법

재킷 옆에 반달 모양의 CD 디스크를 놓고, 디스크가 시계 방향으로 10초에 정확히 1회전하는 영상을 만드는 절차입니다.

프레임은 Python(PIL)으로 한 장씩 회전 렌더링하는 절차적 생성 방식으로, **영상 생성 모델을 사용하지 않습니다**. 10초 루프를 만들고 곡 길이에 맞춰 반복한 뒤 곡을 얹습니다. 원본 이미지 자체를 회전시키므로 디스크 디자인이 열화되지 않습니다.

「Fleeting Four Seasons (Japanese ver.)」에서 완성된 형태의 기록입니다.

## 전체 흐름

작업은 2단계입니다. **먼저 소재로 '완성 이미지'를 만들고, 그다음 Python으로 영상으로 만듭니다**. 순서를 바꾸지 마세요.

**1단계: 소재 → 완성 이미지 (정지 이미지 만들기)**

1. 재킷: 블랭크 재킷의 디자인 면(검은 카드)에 재킷 디자인을 합성해 '완성 재킷 이미지'를 만든다
2. 디스크: 블랭크 디스크를 바탕으로, 재킷 디자인에서 디스크 디자인을 만들어 '디스크 텍스처'를 만든다 (규칙은 아래 '디스크 디자인 규칙' 참조)
3. 완성 재킷 + 디스크를 완성 형태의 배치로 나란히 놓은 '밸런스 확인용 정지 이미지'를 만들고, 여기서 승인을 받는다

**2단계: 완성 이미지 → 영상 (Python)**

4. `make_cd_video.py`로 10초 루프(1회전)를 렌더링한다
5. 루프를 반복하고 곡을 믹스해 곡 길이에 맞춰 자른다

`make_cd_video.py`가 받는 것은 1단계에서 만든 완성 이미지뿐입니다. 디자인의 판단은 모두 1단계에서 끝내 두는 것이 이 방식의 핵심입니다.

## 완성 형태 사양

| 항목 | 값 |
|---|---|
| 프레임 | 1080×720 (3:2) |
| 배경 | 흰색 |
| 재킷 | 왼쪽에 720×720 |
| 디스크 지름 | 640px (재킷 높이 720 기준) |
| 디스크 위치 | 중심이 재킷의 오른쪽 끝과 일치. 오른쪽 절반만 보이는 반달 |
| 회전 | 시계 방향 (실제 CD와 같은 방향), 10초에 정확히 1회전, 일정한 속도 |
| 루프 | 10초 (240프레임 @24fps)를 반복해 곡 길이에 맞춤 |
| 소리 | 곡을 그대로 믹스. 영상 길이 = 곡 길이 |
| 출력 | H.264 / yuv420p / bt709 / faststart (iPhone에서 재생 가능한 형태) |

## 준비물

- 재킷 이미지 (완성품. 케이스가 포함된 이미지여도, 디자인 면만 있어도 됨)
- 디스크 디자인 이미지 (정사각형·원형 디스크 텍스처)
- 곡 파일 (길이는 이 파일에 맞춤)

## 소재 베이스 (필수)

토대가 되는 블랭크 소재를 고정해 두지 않으면 케이스와 디스크의 치수와 위치가 매번 달라집니다. 이 4점을 기준으로 하세요 (저장소 루트, 모두 1600×1600).

CD용:

- `IMG_3354.webp` — 무지 검은 재킷 (투명 주얼 케이스, 흰색 책등 띠 포함)
- 디자인 면(검은 카드) 범위: **x 201..1517, y 95..1547**. 디자인은 이 안쪽에 붙인다
- `IMG_3353.webp` — 무지·무인쇄 은색 CD (흰 배경)
- 디스크 중심 **(770, 808)**, 반경 **약 700** (약간 타원에 가까우므로 텍스처화할 때 원으로 정규화)

레코드(LP)용 — 영상 규칙은 CD와 동일 (반달, 10초에 1회전). 레이블 면은 재킷 디자인에서 다시 만든다:

- `IMG_3356.jpeg` — 무지 검은 LP 재킷 (매트한 검은 슬리브, 흰색 책등 가장자리 포함)
- 디자인 면(검은 앞면) 범위: **x 52..1584, y 11..1593**
- `IMG_3357.jpeg` — 무지 검은 LP 레코드 (흰색 무지 레이블)
- 디스크 중심 **(802, 802)**, 반경 **768**, 레이블 반경 **약 327**

재킷의 검은 면이 디자인 면입니다. 블랭크는 사진 위에 덧칠해서 만들지 말고, 무지 물체로 준비하세요 (질감과 치수가 안정되지 않습니다).

## 디스크 디자인 규칙

실제 CD의 인쇄 범위를 지킵니다.

- 바탕색은 디스크 가장자리까지 전체에 칠해도 된다 (전면 솔리드)
- 단, **요소(문자·로고)의 배치는 인쇄 가능한 띠 안쪽**: 바깥쪽은 반경의 93%까지, 안쪽은 허브의 클리어 존(반경의 약 36%)에는 아무것도 두지 않는다
- 조닝 예시:
- 타이틀: 위쪽 중앙
- 작은 마크류: 좌우 중간선 부근
- 곡 목록·정보 행: 아래쪽 중앙
- 권리 표기 같은 작은 문자: 가장자리 안쪽을 따라
- 허브 주변은 클리어 그대로 (블랭크 소재의 허브를 남긴다)

## 절차

위 '전체 흐름'을 작업 단위로 나눈 것입니다 (1~3이 1단계, 4~5가 2단계).

1. **디스크 텍스처를 준비한다** — 디스크 디자인을 정사각형 텍스처로 만든다. 원의 중심과 반경을 소재에 맞춘다 (생성 이미지의 원 검출은 그림자나 배경에 끌려가므로, 채도 마스크의 외접 직사각형으로 맞추는 방법이 안정적이었다).
2. **재킷을 조립한다** — 디자인을 재킷 소재의 디자인 면에 붙인다.
3. **밸런스 확인용 정지 이미지를 1장 만든다** — 완성 형태와 같은 비율·배치로 정지 이미지를 내고, **반드시 승인을 받은 뒤** 영상으로 만든다. 움직인 뒤에 고치면 되돌리는 작업이 커진다.
4. **10초 루프를 렌더링한다** — `make_cd_video.py`가 프레임을 한 장씩 생성해 ffmpeg로 흘려보낸다. 회전각은 프레임 f에 대해 `-360 × f / 240`도 (PIL의 `rotate`는 양의 각도가 반시계 방향이므로, 시계 방향은 음수).
5. **곡을 믹스한다** — 루프를 반복하고 곡 길이에 맞춰 자른다 (아래 명령어).
6. **검증한다** — 0°/90°/180°/270° 부근의 프레임을 뽑아 콘택트 시트를 만들고, 허브가 흔들리지 않는지, 이음새가 보이지 않는지 눈으로 확인한다. 수치 체크만으로 통과시키지 않는다.
7. **새 파일 이름으로 낸다** — 같은 이름으로 덮어쓰면 받는 쪽 클라이언트가 캐시된 이전 버전을 표시할 수 있다. 버전마다 새 이름(…_v2, …_v3)을 붙인다.

## 사용법

```bash
# 밸런스 확인용 정지 이미지
python3 make_cd_video.py --jacket jacket.jpg --disc disc_texture.png --still balance.png

# 10초 루프
python3 make_cd_video.py --jacket jacket.jpg --disc disc_texture.png --loop loop10.mp4

# 곡을 믹스해 완성 (138초 곡의 예)
ffmpeg -stream_loop 14 -i loop10.mp4 -i song.m4a \
-map 0:v -map 1:a -t 138.0 \
-c:v libx264 -pix_fmt yuv420p \
-color_primaries bt709 -color_trc bt709 -colorspace bt709 -color_range tv \
-crf 20 -maxrate 7000k -bufsize 14000k \
-c:a aac -b:a 192k -movflags +faststart -video_track_timescale 15360 \
output_v1.mp4
```

믹스 시 주의: `-shortest`와 스트림 복사의 조합으로는 곡 길이에 맞춰 잘리지 않을 수 있다. 다시 인코딩하면서 `-t <곡의 초>`로 자른다.

디스크·재킷·음원이 정해져 있다는 전제로, AI 에이전트에게 그대로 건넬 수 있는 형태:

```

- 재킷 이미지: <파일>
- CD 디스크 디자인 이미지: <파일>
- 음원 파일: <파일> (영상 길이는 음원에 맞춤)


- 화면 크기 1080×720 (3:2), 배경은 흰색
- 재킷은 왼쪽에 720×720으로 배치
- CD는 재킷의 오른쪽 끝에 중심을 맞추고, 지름 640px.
오른쪽 절반만 보이는 반달 모양으로 한다
- 먼저, 이 구성의 밸런스 확인용 정지 이미지를 1장 보여줄 것.
승인한 뒤에 영상으로 만들 것


- 시계 방향, 10초에 정확히 1회전, 일정한 속도
- 중심은 움직이지 않고, 흔들림·줌 없음
- 디스크의 인쇄는 디스크와 일체로 회전시킨다


- 음원을 그대로 믹스하고, 회전 루프를 이어 붙여 음원 길이까지 늘린다
- H.264 / yuv420p / bt709 / faststart, iPhone에서 재생 가능한 형식
- 출력 파일 이름은 매번 새 이름으로 한다 (덮어쓰지 않음)
```

## 또 하나의 형태: 9:16·반달만의 영상 (재킷 없음 버전)

재킷을 나란히 놓지 않고, **디스크만** 크게 보여주는 형태입니다. 디스크의 중심을 화면의 왼쪽 끝에 놓고, 오른쪽 절반만 보이는 '반달'인 채로 회전시킵니다. 디스크 디자인 자체를 보여주고 싶을 때의 형태이며, CD 키트의 표준 형태(9:16)이기도 합니다.

흐름은 같은 2단계입니다. 1단계에서 디스크 텍스처를 완성하고(재킷은 만들지 않음), 2단계에서 `--layout halfmoon`을 지정해 영상으로 만듭니다.

| 항목 | 값 |
|---|---|
| 프레임 | 720×1280 (9:16) |
| 배경 | 흰색 |
| 재킷 | 없음 |
| 디스크 위치 | 중심이 화면의 **왼쪽 끝·세로 중앙** (x=0, y=높이÷2). 오른쪽 절반만 보임 |
| 디스크 지름 | 화면 높이 × 0.89 (720×1280이면 약 1140px). 위아래에 약간 여백이 남는 크기 |
| 회전 | 시계 방향, 10초에 정확히 1회전, 일정한 속도. 중심은 움직이지 않음 |
| 소리 | 넣지 않거나(무음), 3:2 버전과 같은 절차로 곡을 믹스 |

사용법:

```bash
# 밸런스 확인용 정지 이미지
python3 make_cd_video.py --layout halfmoon --disc disc_texture.png --still balance.png

# 10초 루프
python3 make_cd_video.py --layout halfmoon --disc disc_texture.png --loop loop10.mp4
```
